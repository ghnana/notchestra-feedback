# Notchestra — Feedback & Bug Reports

This is the public feedback home for [Notchestra](https://notchestra.app), the macOS app
that traces your music around the MacBook notch.

- 🐛 **Found a bug?** [Open a bug report](../../issues/new?template=bug_report.md) — please include
  the diagnostics text (menu bar icon → **Copy Diagnostics**), it tells us your exact machine and state.
- ✨ **Skin idea or feature request?** [Tell us](../../issues/new?template=feature_request.md).
- 💬 Quick questions: [@asaredev on X](https://x.com/asaredev).

Notchestra is private by design — nothing in the app phones home, so this repo (and X) is how we hear from you.
